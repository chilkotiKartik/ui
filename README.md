**UI KARZO** is a stunning, futuristic **UI kit + landing experience** that blends clean aesthetics, smooth interactions, and advanced layouts — ideal for SaaS startups, portfolios, modern product landings, and futuristic platforms.

Whether you're presenting a new product or just showcasing your creative edge — UI KARZO is designed to **leave a bold first impression**.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/chilkotiKartik/ui-karzo.git
cd ui-karzo
````

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```
